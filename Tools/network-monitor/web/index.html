口径、采集与停止方式

Ping 的 0 ms 表示低于计时精度；抖动是相邻成功样本 RTT 差值的平均。P95 表示 95% 成功样本不超过此值。

采集来自本机及源站，通过 SSH 取回源站计时结果。浏览器关闭后仍采集；本机关机或停止程序后留空。系统 VPN/TUN 可能改变实际路径。

停止：运行 Tools/network-monitor/start.ps1 -Stop。不会修改线上配置或重启业务。
