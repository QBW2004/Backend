# MTH 网络链路观测

Windows 本机独立网页：[http://127.0.0.1:18766/](http://127.0.0.1:18766/)。仅监听回环地址；浏览器看到的是运行采集器的这台电脑的数据。

## 打开与停止

双击 `start.bat`，或在仓库根执行：

```powershell
.\Tools\network-monitor\start.ps1
.\Tools\network-monitor\start.ps1 -Stop
```

重复打开复用已运行的采集器。关闭浏览器只暂停页面刷新，采集器继续记录；停止命令会同时结束 SSH 与本轮远端 Ping 进程。未安装开机任务。本机关机或休眠期间不会产生数据。

依赖：Windows、Python 3.10+、系统 OpenSSH。全部 Python 模块来自标准库，不需要 pip/npm 安装；源站使用既有 `mth-server` SSH 配置和密钥，严格校验主机指纹，不复制凭据到代码。没有源站 SSH 权限时，源站线路标为采集缺失，其余线路仍可用。

## 四条测量路径

| 路径 | 方法 | 间隔与超时 | 解释 |
|---|---|---|---|
| 本机 → 中转 185.180.17.57 | Windows ICMP API | 每 2 秒；1.2 秒超时 | 网络往返时延、ICMP 未回包率 |
| 源站 8.218.67.82 → 中转 | 源站 .NET Ping，SSH 返回结果 | 每 2 秒；1.2 秒超时 | 反向测量两服务器之间的往返；RTT 不包含 SSH 传输耗时 |
| 本机 → 中转 → 源站 | HTTPS `HEAD /` | 每 10 秒；8 秒超时 | 连接到真实中转 IP，保留域名 SNI 和证书校验；含 TLS、转发、服务器响应耗时 |
| 本机 → 源站直连 | HTTP `HEAD /`，8080 | 每 10 秒；8 秒超时 | 直连对照，不含 TLS；与经中转 HTTPS 的差值不能直接当作中转网络开销 |

现场源站不回复外部 ICMP，因此使用反向 Ping；没有开放源站防火墙。各段 RTT 不能简单相加得到玩家游戏延迟。ICMP 不回复也可能源于限速或过滤，不能直接当作游戏丢包；HTTP 的失败率是请求失败率。探测不连接 9000、子游戏端口或业务管道，不登录、不下注、不写业务库。

界面支持 5 分钟、15 分钟、1 小时、6 小时、24 小时窗口，暂停查看、恢复实时、悬停曲线/失败时间带及原始 CSV 导出。窗口统计不会补造程序停止期间的数据。均值/P95 只用成功样本；抖动只用相邻且间隔合理的成功样本。采集异常独立显示并排除出失败率分母。

HTTP 状态 200/301/302/303/307/308 视为匿名网页探测成功，其余状态或连接异常视为请求失败。代理/VPN/TUN 会影响实际访问路径；本工具不自动改变系统代理。界面中的“本次测量”在最新探测失败、数据过期或采集断开时显示 `—`。

## 保存与配置

- 配置统一在 `config.json`：地址、SSH 别名、网页端口、间隔、超时、保留天数；修改后停止再启动。
- 数据在仓库 `.build/network-monitor/history.sqlite3`，按本机接收时间记录 UTC 毫秒；页面统一显示 UTC+8。远端结果超过 10 秒的时钟偏差/传输滞后计采集缺失。
- 保留最近 7 天，每小时清理仅属于本工具的旧采样；SQLite 复用释放的页。页面最多回看最近 24 小时，CSV 同当前窗口。
- 日志 `.build/network-monitor/monitor.log`，每份最多 1 MiB、2 份轮转，不记录凭据。
- 源站探测脚本通过 SSH 内存执行：单会话最多 60 秒后正常续接，续接会有短暂的真实采样空隙。正常停止时按源站 PID 和本轮随机标识双重核验，只结束本工具的采集进程；本机异常退出/SSH 失联时远端最长 60 秒自动结束。源站没有写入脚本、安装服务或新增计划任务。
- Web API 固定路径白名单，无任意目标探测接口；回环绑定、Host 校验、无 CORS、停止操作需要自定义请求头，不允许外站直接读取或停止采集。
