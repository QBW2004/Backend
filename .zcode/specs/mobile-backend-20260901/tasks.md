# Implementation Plan: 手机端后台第二轮改造

## Overview

本计划按“先确定性基础设施与权限、再页面、最后开奖历史外部联调”的顺序实施。当前工作区已有未提交修改，所有任务必须只触碰本需求相关文件并在每个阶段重新检查 `git diff`。

**测试纪律（非协商）：**

- 每个后端实现任务必须配套自动测试或可重复 SQL 验证；没有验证不算完成。
- 构建时间较长，后端每个 wave 结束执行一次 `Tools\dev\build.bat`；纯 CSS/文案调整优先浏览器手测，避免无意义重复全量构建。
- 最终门槛：Release 构建零错误、相关测试全绿、数据库迁移幂等、手机/电脑入口手测通过、权限越权请求被服务端拒绝。
