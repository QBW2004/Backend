# 多客户端包与代理线隔离（2026-10-30，2026-10-30 随 1.0.71 上线）

> 2026-11-06 新规则已本地实现、未部署：排行榜和大奖播报改为“有专属桌只看专属，否则只看公共”，公共桌真人与机器人同范围；游戏仍须开放且本线可玩。下文“本线＋公共”及“不带 account 混合全榜”为旧版本记录。源码、SQL 与配套发布边界见 [排行榜三端联调](大厅排行榜-三端联调.md)。

> SQL 归档说明（2026-11-05）：本页涉及的历史 SQL 已移至仓库外，原发布/验收事实保持不变；原文位置见 [归档索引](../Database/legacy-sql-archive.md)。当前初始化以 Database/README.md 为准，不按历史清单重跑。

> 发布结果、构建与人工验收边界见 [后台与服务端发布-20261030](后台与服务端发布-20261030.md)。以下保留实现时的步骤与说明；本轮已完成后台/MSVC 构建与相关回归。客户端未出包。

方案与名词见 claude.ai 项目文档「多客戶端包與代理線隔離-2026-10」。本文只记三个仓库实际改了什么、怎么上线、怎么验收。

一句话：多套不同界面的 APK/IPA 共用同一套服务端，靠登录包里的**包口令**区分；每个超管直属代理（“线”）可以限定**玩家可玩游戏**，并可以有一套**自己的桌台参数**（专属桌台）。排行榜、中奖播报、控制页都只显示本线可玩的游戏。

## 一、确认过的决定

1. 客户端包只是换皮，和代理线无关，任何线的玩家都能用任何包；后台可以启停每个包。
2. 标识客户端包用大厅登录包里已有的口令字段（换值，不改字节布局），不在登录包或选桌包里新增字段。
3. 超管创建直属代理时必须勾选「玩家可玩游戏」（至少一款），整条线（该代理及其下级代理、玩家）只能玩、只能看到这些游戏。
4. 桌台设置只按「直属代理」区分，**没有**「游戏客户端」选项（2026-10-30 再次确认）。
5. 某条线分到专属桌台后，这条线的玩家必须用「按真实桌号显示」的新包进这款游戏。

## 二、改动清单

### 数据库

`Docs/sql/多客户端包与代理线-20261030.sql`（MTH-Server `docs/sql/` 同一份，幂等，只加表加列）：

- `clientpackage`：客户端包，原口令 `CDhP53fFb822` 登记为 1 号默认包（按连续位置选桌）。
- `admin.PlayableGames`：直属代理的可玩游戏，NULL = 不限（存量代理全是 NULL）。
- `roomtableowner(GAME_ID, RoomIndex, TableIndex, LineAgent)`：桌台归属，没有记录 = 公共桌台，`#` = 已收回。
- `gameprizerecord.LineAgent`、`gamerankhistory.LineAgent`：中奖记录与大厅排行榜按线隔离，排行榜 30 槽环形改为「线 × 游戏」。

### 服务端（MTH-Server）

- `Common/LineScope.h`、`Common/LineScopePoco.h`：编解码、子游戏侧登记、选桌过滤、入座校验、播报过滤。`Common/Message.h` 新增 0x5530~0x5534。
- 中心服：登录按口令识别包（查不到/停用回 -5）；进子游戏校验本线可玩、有专属桌台时校验包能力；向子游戏下发用户范围与桌台归属；排行榜与大厅播报按线。
- 线上开放的 13 款子游戏（火凤凰、大字板、ATT满花版、点石成金、NBA、麻将胡了、金蟾、李逵、彩金单挑、幸运六狮、水果拉霸、明星97、水浒传）：连上中心服发握手；接收用户范围/桌台归属；登录回包的桌台配置块只发本线看得到的桌；查桌、入座校验桌号属于本线；中奖播报与中奖记录带归属线；心跳下发播报按线过滤。麻将胡了自动配桌时只挑本线的桌。
- 机器人入座的桌号上限由 50 放宽到 `MAX_TABLES`(256)：专属桌号接在公共桌台之后，可能超过 50（9 款鱼机/牌机/押注服）。
- 进子游戏被中心服拒绝时的断开原因码细分（`LineScope::CloseFlagForLoginRet`）：本线不可玩（中心服 -6）→ `CLOSE_FLAG_GAME_NOT_PLAYABLE` 0x09，有专属桌台但包不支持真实桌号（-5）→ `CLOSE_FLAG_CLIENT_UPGRADE` 0x0A，冻结（4）仍是 0x08，其余仍是 0x01。9 款牌机/鱼机/押注服直接用作断开码；拉霸三款登录失败时对 9/10 先下发 `MSG_FORCE_LOGOUT` 再断开（其余失败照旧只回失败包）。麻将胡了未改（仍回 `login_failed`）。
- 李逵劈鱼中心服链路 `COM_RECV_OTHER_GAME_MSG` 漏写 `break` 落到 `COM_UPDATE_MONEY_TYPE` 多读字节，顺手补上。
- 验证：`tests/line_scope_test.cpp`（g++）93 项通过；改动前后逐文件 g++ 打桩语法比对，错误集一致（只有 Windows API 打桩缺失）；**尚未 MSVC 编译**。

### 后台（本仓库）

- BLL：`EF/LineScopeRules.cs`（可玩游戏、所属线，与中心服同口径）、`EF/LineTables.cs`（专属桌台复制/收回、删桌时归属左移）、`EF/ClientPackages.cs`；`M_Admin.PlayableGames`（NotMapped，原生 SQL 读写，补丁未执行时按不限处理）。
- 代理管理（电脑端/手机端）：超管添加代理时勾选可玩游戏（默认全选，至少一款）；列表新增「可玩游戏」列与修改入口（仅直属代理）；代理详情显示所在线的可玩游戏。接口 `GetPlayableGames`、`SavePlayableGames`。
- 游戏配置（桌台设置）：新增「代理」下拉（公共桌台 + 超管全部直属代理）。选中某线时只列该线专属桌台，保存/删除走原接口和热更；没有专属桌台时可「从公共桌台复制一套」（各按桌表原样复制，桌名 1号机…N号机，优先复用已收回桌号，同步房间桌数后 RP 热更）；「收回专属桌台」后该线回到公共桌台。专属视图里不能直接新建桌台；已分配过专属桌台后再新建公共桌台会先确认（新桌排在专属桌之后，老包进不了）。删除桌台时 `roomtableowner` 跟着各按桌表一起左移。
- 机器人设置（2026-10-30 晚）：「添加机器人」新增「代理线」下拉（公共桌台 + 在该游戏有专属桌台的直属代理），桌子下拉只列所选线的桌（`GetRobotLineOptions`、`GetRobotTableList?Line=`，公共桌台的值是 `_public`），保存时校验桌子属于所选线；列表新增「代理线」列和筛选（全部/公共桌台/各直属代理/已收回）。「收回专属桌台」时一并删除这些桌上的机器人设置并通知机器人服热更（`LineTables.RecallLine`）。机器人在专属桌台中的大奖只归该线。
- 客户端包管理（新菜单，超管）：登记包口令、启停、选桌方式（真实桌号/连续位置）。默认包口令不能改。
- 接口：`/Api/Games?account=`、`/Api/RankingList/History?...&account=` 按玩家所在线过滤；不带 account（老包）口径不变。
- 控制：控牌/总控/鱼机控制的游戏下拉只列登录账号所在线可玩的游戏（页面注入 `MTH_PLAYABLE_GAMES` / `MConfig.playableGames`）；保存时按目标玩家所在线再校验。
- 契约测试：`UnitTestProj/LineScopeRulesTest.cs`（新增，含与中心服 `cardActionToGameId` 逐项比对）。本机未能编译 C#，上线前须 `Tools\dev\build.bat` + UnitTestProj 全绿。

### 客户端（MTH-git）

- `Network.ClientAppKey`：登录口令常量，默认仍是 `CDhP53fFb822`（= 1 号默认包），**出新包时换成新口令**并在后台登记。
- `Network.AccountQuery`：游戏列表、排行榜请求带上 account；大厅登录成功后立即按新账号重新拉取游戏列表（`Games.RefreshNow`），退出到登录界面换账号登录时不用等 100 秒轮询，旧账号的慢请求晚到会按序号作废。
- `Network.TableIndexAt / TablePositionOf / GetTableConfigAt`：选桌桌位按配置块里的真实 TableIndex 生成。牌机（火凤凰/ATT满花版共用、大字板、NBA、点石成金，及未接线的 ATTManHuaBan/ATTZhiZun 副本）、鱼机（CommonFish）、押注（彩金单挑、幸运六狮）选桌改用它；游戏内“第几桌”按桌位显示。
- 强制下线提示：`UIGlobalAssist`（牌机/押注）、`CommonFish/LibAlg`（鱼机）、`Util.ForceLogoutToLogin`（Lua 拉霸）新增 9「该游戏暂未对您开放，请联系您的代理」、10「当前客户端版本过旧，请更新到最新版本后再进入」（鱼机与 Lua 通道顺带补上 8 冻结）。老包收到 9/10 显示「强制下线，错误代码：9/10」。
- 拉霸三款的 Lua 选桌桥本来就按服务端下发的 tableId 选桌，麻将胡了由服务端自动配桌，都不用改。
- Unity 2021.3 编译通过（Assembly-CSharp 已重编，无报错）；**未出包**。

## 三、上线顺序

1. 线上库 `mysqldump --single-transaction --hex-blob --routines --triggers` 备份后执行 SQL 补丁。
2. 后台、中心服、13 款子游戏一起发布（中心服按标准重启流程）。此时 `PlayableGames` 全为 NULL、没有专属桌台，玩家体验与现在一致；排行榜/播报开始记录归属线。
3. 出新包：每套包把 `Network.ClientAppKey` 换成自己的口令（6~32 位字母或数字），后台「客户端包管理」新增并选“按真实桌号显示”。
4. 超管在代理管理里给直属代理设置可玩游戏；需要分线调参的游戏，在游戏配置里选中该代理 →「从公共桌台复制一套」→ 逐桌修改。**公共桌台要加桌请在分配专属桌台之前加。**

## 四、人工验收（测试服）

1. 客户端包：未登记口令的包登录提示升级；停用某包后该包新登录被拒、在线不踢；1 号默认包口令不可改。
2. 可玩游戏：超管新建直属代理 A 只勾选 2 款；A 下的玩家（新包）大厅只显示这 2 款；老包能看到全部图标，但进其他游戏被拒。修改勾选后玩家下次进游戏生效。
3. 专属桌台：游戏配置选代理 A →「从公共桌台复制一套」，左侧出现 1号机…N号机，改某桌押注上限后保存热更；A 线玩家（新包）进该游戏只看到这 N 张桌、参数是改过的；其他线玩家仍看到公共桌台；A 线玩家用老包进该游戏提示升级。「收回专属桌台」后 A 线玩家重新进游戏回到公共桌台。
4. 删除桌台：在公共视图删一张公共桌后，A 线专属桌台的归属仍正确（列表不串线）。
5. 机器人：添加时选代理线 A；牌机填写增加人数，实际随机找本线空机台，鱼机/押注/拉霸仍按本线桌子选择。保存后列表「代理线」列显示 A；「收回专属桌台」后这些机器人设置消失。1.0.72发布记录见《牌机机器人发布-20261030》。
6. 排行榜与播报：A 线玩家中大奖，B 线玩家（新包）排行榜和跑马灯都看不到；公共桌台上机器人的大奖两边都能看到；只显示本线可玩游戏。
7. 控制：A 线代理登录后台，控牌/总控游戏下拉只有 A 的可玩游戏；对 A 线玩家下 A 不可玩游戏的控牌被拒。

## 五、风险与待验证

- 各子游戏 RP 扩容后新桌的奖池/状态文件（DscjSave.bin、NBASave.bin、DaZiBan.bin、JackpotState.txt）是否自动补默认值，测试服先验。
- 鱼机、押注是多人同桌，分线后每条线人更少；复制专属桌台时 `robot_seat` 跟着复制，机器人照常上桌。
- 老包不带 account：游戏列表与排行榜维持旧口径（排行榜是各线混合的最新 30 条），中奖播报照常按线过滤。
- 可玩游戏与包能力只在进子游戏时校验，正在游戏中的不踢。
- 排查「进游戏选桌被强制下线，错误代码：1」：看线上中心服日志 `C:\Server\Logs\中心服务器日志.log`，搜玩家账号。有 `CheckLogIn 代理线范围拒绝 id=… gameID=… ret=…` 就是范围拒绝（-6 该线没勾这款游戏，-5 有专属桌台但用的是老包/默认口令包）；没有这行就看 `服务中心登录返回值 0 成功  <账号> <ret>` 的 ret，属于原有登录校验（1 不在线等）。
