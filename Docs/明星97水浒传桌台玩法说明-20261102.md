2026-11-02 已实现并验证，未发布。

入口：游戏配置 → 桌台配置 → 明星97／水浒传 → 选择已保存机台 → 拉霸出货权重与理论 RTP。

页面原来共用“启用原包额外玩法”，但明星97根本没有相应玩法，水浒传小玛丽也不受该开关控制；普通连线类别的整盘平均赔付又被取整显示，容易被当作游戏内单条线赔率。本轮在现有水果机说明的模式上补齐两款的图案名、连线／全盘定义、赔率及额外玩法规则。

- 明星97：说明A～H八线、樱桃线首一／二连、三连、混合BAR、ALL N个7、全水果及全盘同图案；全盘奖按单线注、不叠加线奖。明确没有明星倍／BONUS／系统奖，隐藏无效开关。7三连按ALL 3个7的5倍结算，两类权重共同贡献这一结果。
- 水浒传：使用“水浒传（万能图标）”“人物（宋江／林冲／鲁智深）”“兵器（刀／枪／斧）”描述，补双边连线及总注全盘奖。BONUS GAME（小玛丽）固定按同线从任一端连续3／4／5个万能送1／2／3次，每线按较长一端、九线相加最多27次；散落万能或只有中段相连不触发。说明外圈匹配、内圈三同20／四同500倍、退出扣次数、回合上限；外圈权重决定进入后的停位，不改变触发条件。
- 普通连线卡片改为“本类整盘平均”，最多保留3位小数，区别于帮助里的单条线固定赔率；水浒传全盘奖直接标总押注倍数。
- 水果机继续显示两个独立奖池，开关改为“使用自定义幸运灯奖池（水果机）”。隐藏的明星／水浒旧 extra[0] 保存值原样保留；不改算法、目录指纹、协议、数据库结构或已存权重。
