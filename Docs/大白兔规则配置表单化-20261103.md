# 大白兔机台「独立玩法规则」改为中文表单

2026-11-03 实现，未发布。

运营反馈机台配置页的「大白兔独立玩法规则」只是一整段 JSON 输入框，无法直接维护。现改为按中文分区表单编辑，区块与 `RabbitConfig`（`TTY.Web/Models/RabbitConfig.cs`）和服务端 `RabbitRules.h` 的校验口径一一对应：

- **基础**：小四梅固定倍率、特殊奖揭示超时（正宗大四梅与五枚共用，服务端强制一致）。
- **正宗大四梅**：启用开关、基础倍率、X1~X14 倍数档与相对权重（可增删档，显示权重合计）。
- **五枚赠送**：启用开关、基础/中赠/落空倍数、自然与强出中赠概率（分子/分母，实时显示约等于百分比）。
- **连庄（烧火送小四梅）**：启用开关、烧火窗口、押分入池万分点、初始奖池、次数档权重、起手/续庄/断档复燃/补第二张鬼/鬼排首位概率、末局保底与屏蔽更高奖开关。
- **过关与爆机彩金**：两个独立开关与目标分/彩金分（比倍玩法中达标即发，爆机锁机只能收分）。
- **留机**：每日次数上限；最少手数标注为兼容字段（2026-11-02 起服务端不再按手数拒绝）。
- **全兔赛跑**：启用开关、活动编号（服务端校验只增）、开始/结束时间（datetime-local，转 unix 秒）、总额度、奖励倍率。

## 实现口径

- 载入：`GetRabbitConfig` 返回的 JSON 经 `deepFill` 与前端 DEFAULTS（与 `RabbitConfig.DefaultJson` 逐字节一致，已脚本核对）合并，缺键补默认、未知键原样保留。
- 保存：表单回填同一 JSON 结构，仍走 `SaveRabbitConfig(tableIndex, configJson)` 与既有服务端完整校验/热更，提交合同不变。
- 概率一律「分子/分母」两个整数输入，不让运营写小数；权重档可增删（至少保留一行）。
- 原始 JSON 折叠为只读预览，随表单实时生成，便于核对实际下发内容。
- 说明文字与 `ServerCardPhenix` 语义逐条核对：正宗大四梅=大四梅无鬼自然开出按权重翻倍；五枚=五梅中赠/落空两档；连庄=入池+窗口连送小四梅；过关/爆机=比倍达标发彩金、爆机锁机；赛跑=小四梅及以上按倍率送分、额度送完即止。
