# 机器人账户批量删除缺失依赖修复（2026-11-01）

## 线上原因

1.0.90 发布批量创建/删除时仅更新 `YYT.Web.dll`、页面和版本号，漏带新增 `B_UserRobot.AddRobots` / `DelRobots` 的 `YYT.BLL.dll`；1.0.91 继续沿用了旧 BLL。

- IIS 日志：台北时间 21:01:05～21:03:18，`POST /Game/Robot/BatchDeleteRobotAccounts` 连续 HTTP 500。
- 线上 BLL 时间为 01:00:46，反射确认没有这两个方法。
- 对线上 Web 接口执行 `RuntimeHelpers.PrepareMethod`，分别复现两个 `MissingMethodException`。错误发生在方法 JIT 阶段，未进入 action 的 try/catch，更未执行数据库删除。
- 批量创建同样受影响。单条删除使用旧 `DelRobot`，不是本次缺失方法问题。

## 修复与发布

2026-11-01 21:14:20 已上线 **WebVer 1.0.92**，标准 `deploy.ps1 -Yes -Port 8080` 发布耗时 16.24 秒。

- 仅修改 `Web.config`（保留 UTF-8 BOM）与 `bin/YYT.BLL.dll`。
- 基于线上依赖隔离编译 BLL；排除工作区尚未发布的总控能力改动。完整 IL 方法比对后，除 `B_UserRobot` 外所有方法不变；归一化编译器闭包编号后，公开方法差异只有新增 `AddRobots`、`DelRobots`，原有方法逻辑不变。
- 线上 1548 个发布文件逐一与暂存比对通过；`YYT.Web.dll`、页面及其他 DLL 保持原字节。
- 16 个 Server/Daemon 的 PID 全部不变，14 个玩家端口监听正常，8080/8081 HTTP 200。
- 发布前后 `userrobot` 均为 240 行。本次没有在生产创建或删除机器人账户、改 SQL 或重启游戏服/Robot。
