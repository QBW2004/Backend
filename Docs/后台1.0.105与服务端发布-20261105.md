状态：**已上线**。00:13:46（Asia/Taipei）发布任务完成。后台 1.0.104 → 1.0.105，整站 1578 个文件；服务端更新 10 款 exe/PDB。无 SQL 迁移、无 APK，未更正历史资金记录。

## 上线内容

- 后台：大白兔/火凤凰规则 JSON 读取修复；专属桌台复制/收回确认框依赖失败时的浏览器确认回退；麻将胡了 RTP 三秒估算与后台继续精确复核；麻将代理线复制默认配置、恢复跟随默认配置。
- 本轮发布补充：共享布局输出的 jquery-js 资源均追加 WebVer，确保 common.js 确认框修复随 1.0.105 刷新缓存。Web.config 保留线上原有配置，仅递增版本。
- 六款在服牌机：点石成金、ATT、大字板、NBA、火凤凰、大白兔，送牌换牌命中与离场开奖记账修复，大白兔连庄逐手记账并在整组结束消耗次数。
- 彩金单挑/幸运六狮：选中被控玩家后保留本局总押注，后续玩家不再清零。
- 金蟾捕鱼/李逵劈鱼：小放强度 1～3、10≤倍率<100 的基础命中率 18% → 19.5%，其他条件保持。

中心服、麻将、三款拉霸、Robot 二进制未替换。金皇冠同源修复提交入库但不发布、不启用。

1. 初次只读预检时线上所有 Server 进程已停止、在线玩家为 0，Daemon 仍在运行。日志显示上一轮停服发生于 11-04 23:59:12～23:59:18，本次未触发该次停服。

3. 按本次用户部署指令执行维护切换，明确使用 `-AllowDisconnect`，保留机器人停止状态。计划任务 `MTH_Deploy_1_0_105_20261105` 使用 SYSTEM 脱离 SSH 会话。

5. 00:13:25 重试预检在线 0、进程 0；00:13:26 完成备份并替换 10 款，00:13:29 发全启，00:13:44～00:13:46 三个 HTTP 探活均 200，计划任务退出码 0。维护窗口从首次停服至验证恢复约 80 秒，包含脚本修正时间；原在线玩家需重连。
6. 当前中心 + 14 款游戏共 15 个单实例；Robot 原先停止，本次保持停止，未修改 robots 配置或账号。
