# 玩家列表性能优化 - 验收测试指南

## 测试环境准备

### 前置条件
- 手机端后台系统正常运行
- 测试账号具有代理权限
- Chrome DevTools 或等效工具用于性能监控

### 测试数据要求
- **在线玩家**：至少 10-50 个在线玩家
- **离线玩家**：至少 2000-3000 个离线玩家
- **控制状态**：部分在线玩家有吃分/放水等控制状态

---

## 测试用例

### 1. 在线玩家加载速度测试

**测试步骤**：
1. 清除浏览器缓存
2. 打开手机端后台：`/Mobile/Home/Index`
3. 使用 Chrome DevTools Performance 记录
4. 观察"在线"标签页的加载

**验收标准**：
- ✅ 玩家卡片基础信息（账号、昵称、余额）**立即显示**（< 0.3秒）
- ✅ 控制状态（吃分/放水信息）**延迟显示**（0.3-0.5秒后补充）
- ✅ 页面无白屏或长时间 Loading
- ✅ Network 面板显示控制状态请求**不阻塞**页面渲染

**性能指标**：
```
优化前：0.5秒
目标值：< 0.3秒
实测值：_______秒
```

---

### 2. 离线玩家加载速度测试

**测试步骤**：
1. 点击"离线"标签页
2. 记录首屏 10 条玩家的加载时间
3. 观察是否有"控制状态"请求

**验收标准**：
- ✅ 离线玩家卡片**立即显示**（< 0.8秒）
- ✅ Network 面板**无控制状态请求**（GetActiveTotalControls）
- ✅ 页面流畅，无卡顿

**性能指标**：
```
优化前：2秒+
目标值：< 1秒
实测值：_______秒
```

---

### 3. 离线玩家翻页性能测试

**测试步骤**：
1. 在离线标签页，点击"加载更多"
2. 重复点击 3-5 次
3. 观察每次加载时间

**验收标准**：
- ✅ 每次翻页加载时间 < 0.5秒
- ✅ 滚动流畅，无明显延迟
- ✅ 无控制状态查询请求

**性能指标**：
```
优化前：1秒+
目标值：< 0.5秒
实测值：_______秒
```

---

### 4. 刷新按钮防抖测试

**测试步骤**：
1. 快速连续点击右上角"刷新"按钮 5 次
2. 观察页面响应和 Network 请求

**验收标准**：
- ✅ 第 2-5 次点击显示提示："正在刷新中，请稍候..."
- ✅ Network 面板只有 1 组请求（3个接口），无并发重复请求
- ✅ 页面无卡顿或假死

**性能指标**：
```
优化前：假死 2-3秒，多组并发请求
目标值：流畅响应，单组请求
实测值：□ 通过 / □ 失败
```

---

### 5. 控制状态缓存测试

**测试步骤**：
1. 首次加载在线玩家页面（观察 Network）
2. 等待 10 秒
3. 点击刷新按钮
4. 观察控制状态请求

**验收标准**：
- ✅ 首次加载：发起控制状态请求
- ✅ 30秒内刷新：**无控制状态请求**（使用缓存）
- ✅ 30秒后刷新：重新发起控制状态请求

**性能指标**：
```
缓存命中时：0秒（无请求）
缓存未命中时：0.3秒
实测值：□ 通过 / □ 失败
```

---

### 6. 功能完整性测试

**测试步骤**：
1. 验证在线玩家的控制状态是否正确显示
2. 点击玩家卡片，验证玩家详情弹窗
3. 验证排序功能（最后登录、盈亏排序）
4. 验证搜索功能

**验收标准**：
- ✅ 控制状态信息准确（吃分目标、已吃金额等）
- ✅ 玩家详情弹窗正常打开
- ✅ 排序功能正常工作
- ✅ 搜索功能正常工作

---

### 7. 极端情况测试

#### 7.1 大量在线玩家（100+）
**测试步骤**：
1. 模拟或等待高峰期（100+ 在线玩家）
2. 测试加载速度和流畅度

**验收标准**：
- ✅ 首屏渲染 < 0.5秒
- ✅ 控制状态异步加载，不阻塞主流程

#### 7.2 大量离线玩家（5000+）
**测试步骤**：
1. 测试 5000+ 离线玩家场景
2. 测试翻页流畅度

**验收标准**：
- ✅ 首屏加载 < 1秒
- ✅ 翻页流畅，无卡顿

#### 7.3 网络慢速
**测试步骤**：
1. Chrome DevTools → Network → 切换到 "Slow 3G"
2. 测试页面加载

**验收标准**：
- ✅ 基础卡片先显示，控制状态可以延迟
- ✅ 页面不会长时间白屏

## 附录：性能测试工具

### Chrome DevTools 使用
```
1. 打开 DevTools (F12)
2. 切换到 Performance 标签
3. 点击 Record 按钮
4. 执行测试操作
5. 点击 Stop 按钮
6. 分析 Flame Chart 和 Timings
```

### 测量代码示例
```javascript
// 在浏览器 Console 中运行
performance.mark('start');
// ... 执行操作 ...
performance.mark('end');
performance.measure('操作耗时', 'start', 'end');
console.table(performance.getEntriesByType('measure'));
```

### 网络限速设置
```
Chrome DevTools → Network → 
- Fast 3G: 下载 1.6 Mbps / 上传 750 Kbps
- Slow 3G: 下载 400 Kbps / 上传 400 Kbps
- Offline: 离线测试
```
