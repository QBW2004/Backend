## 7. 奖池扣款口径

- `Docs/sql/奖池精准扣除与明细保留-20261103.sql` 重建两个存储过程：
  - `agentprize_record_award`：送奖开奖按上报的本手牌型得分扣，余额不足**扣到 0 为止**；`AwardDiamonds` 记玩家实得，`BookedDiamonds`/流水记实际扣除。
  - `agentprize_release_delta`：放水累计净收益最多扣到 `TargetCoins`，余额不足同样扣到 0；输回时正常返还。
  - 控牌与放水重叠返还沿用原口径，补扣方向同样不使余额为负。
- 送奖下发只要求奖池余额 > 0（用户确认：送出得分大于余额也可送，扣到 0）；放水仍要求余额覆盖目标。
- 服务端（`MTH-Server`）：`ServerCardDazhi`/`ServerCardKing3`/`ServerCardPhenix`（含大白兔）的 `ReportPrizeRecord` 新增 `funded` 参数，**比倍爆机、全兔赛跑、全民赛跑**只记中奖明细/播报，不再按送奖控制编号扣奖池（用户确认彩金/额外得分不计入送奖支出）。麻将胡了按实际送出得分扣，不改。
