# 后台文档导航

本库保存后台当前工作指南和必要的实施、数据迁移、验收与发布证据。先从下列指南进入源码，再按需要查证据；旧专题中的“当前/未发布/下一步”只表示记录当时的状态，不是现在的待办清单。生产现状必须另行核实。

## 每次改功能的入口

1. 读 [根 AGENTS](../AGENTS.md) 和 [三端功能影响图](../../MTH-Server/docs/architecture/feature-impact-map.md)，定位客户端、后台、中心、游戏服、Robot、数据库和资源包的影响。
2. 按 [影响记录模板](../../MTH-Server/docs/architecture/change-impact-template.md) 写受影响项、排除依据、验证和发布依赖；用 [后台源码入口](architecture/backend-features.md) 跟到实际 Controller、BLL、命令和页面。
3. 新增子游戏必须完成 [三端接入清单](../../MTH-Server/docs/architecture/new-game-checklist.md)、[游戏接入矩阵](../../MTH-Server/docs/architecture/game-integration-matrix.md) 和 [后台接入清单](architecture/backend-new-game.md)，逐项留证据或说明不适用；不能只接配置和启动。
4. 按 [开发、验证与交付](architecture/backend-development.md) 选最短有效验证，并记录耗时。
