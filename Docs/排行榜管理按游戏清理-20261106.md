## 功能

- 入口：电脑后台「系统设置 → 排行榜管理」（仅超管，`UserPriv==0` 菜单 + `[SuperAdminAuthorize]`）。
- 列表：只展示客户端排行榜可见的游戏，与 `api/RankingList/History` 同口径（`Enable=1`、牌机/拉霸、排除麻将胡了 54）；停用游戏和残留记录不展示。显示各游戏当前可见条数（`IsBigWin=1 AND Score>=0`，所有代理线合计，无记录显示 0）与最新上榜时间。
- 代理线下拉（2026-11-06 追加）：
  - **全部代理线**：不分桌台，条数为所有专属桌+公共桌合计；清理删所选游戏全部排行行。
  - **公共桌台**：只统计/清理公共桌上的记录（没有专属桌的代理线玩家看到的就是这些）。
  - **某条直属代理线**（如莫线）：与该线玩家客户端所见一致——只列该线可玩游戏；该线在此游戏有专属桌 → 「排行来源」显示**专属桌台**，只算/只删这些专属桌（且写入归属为本线）的记录；没有专属桌 → 显示**公共桌台**，算/删公共桌记录。清理公共桌来源会影响其它同样使用公共桌的代理线，确认框单独列出这些游戏。
  - 公共桌台/代理线两种范围直接复用客户端 `api/RankingList/History` 的 `TableDisplayMap.HistoryVisibilitySql`（按实际桌台坐标在 SQL 中筛选），不另写一套口径；专属判断与其一致（`roomtableowner` 本线且桌台仍在 `roomtableconfig`，`#` 收回桌不算）。
- 勾选游戏（支持全选）→「清理所选」→ 二次确认（含代理线名称）→ 删除所选范围内客户端可见的行；提交的编号先与该范围页面列出的游戏求交集，不可见/不可玩游戏不会被手动清理。客户端重新打开排行榜即不显示。
- 残留每日自动清理：`RankHistoryCleanup.CleanupResidualDaily()` 挂在 `Global.asax` 定时任务（与 `CleanupExpiredRecordsThrottled` 同一轮），每个服务器本地自然日最多执行一次，进程启动后首轮也执行。删除客户端永远看不到的行：`games` 无此游戏、游戏停用、非牌机/拉霸、麻将胡了 54、旧口径 `IsBigWin<>1`、`Score<0`。有删除时写日志 `[RankResidualCleanup] deleted=N`。**注意：游戏被停用后，其排行记录会在当天定时任务中删除，重新开启后从空榜开始。**
- 不删除 `gameprizerecord` 中奖明细，不影响奖池、玩家分数、后台中奖记录；清理后新大奖照常上榜。操作写日志 `[RankClear] operator=... games=... deleted=...`，不可撤销。

## 与游戏服的关系

游戏服 `MTH-Server/ServerCenterNew/RankHistoryStore.h` 写排行时取本线本游戏最新 `Slot+1`（`% 30`），无行时 `slot=-1+1=0`，因此清空后从 0 槽重新环形写入，无需重启或改服务端。
