# 大白兔控牌牌型接入「控制」页

2026-11-02 实现，未发布。

大白兔（cardAction=20，平台 GameId=55）的控牌牌型在总控/控制页放出来：牌型完全参考火凤凰，唯一区别是正宗大四梅扩展挡位到 X14（火凤凰只到 X6）。

## 口径

- 控牌指令号 `20` → 平台 `GameId 55`，与中心服 `ServerCenterRun::cardActionToGameId` 同口径（`case 20: return 55` 已在服务端）。
- 牌型沿用火凤凰（phenix 倍率表）：杂牌(0)/五鬼(12)不提供、大四梅(8)保留、99=关闭控制。
- 扩展控牌「正宗大四梅」：火凤凰 X1~X6 = 控牌值 13-18；大白兔 **X1~X14 = 控牌值 13-26**，文案 `正宗大四梅Xk(80×k倍)`。服务端 `CardAlg` 在 `MTH_DABAITU` 编译分支已把扩展值上限放开到 26（`ctrl_value-12` 取倍数），后台只负责展示与透传。
- 大白兔进入以下全部可选入口：手机「控制→控牌」共享列表 `M.CARD_ACTIONS`、电脑端用户管理/在线玩家的「总控→控牌」`totalCardActionData` 与牌机单控 `actionSelDataPAIJI`。
- 代理线隔离同步生效：电脑端 `window.MTH_CARD_ACTION_GAME` 与手机端 `CARD_ACTION_GAME` 均补 `20: 55`，受限代理线看不到本线不可玩的大白兔；保存时服务端按玩家所在线再校验（`ApplyTotalControl` 已有该逻辑）。
- 历史控牌记录回显：手机 `M.cardTypeName` 与电脑端 `labaTypeName` 的牌机分支均为 `(action >= 5 && action <= 14) || action == 20`，13-26 扩展值经 `valSelDataPAIJI`/`cardTypeDataForPaiji` 正常回显；`GameDisplayNames` 将 GameId 55 显示为「大白兔」。
- 服务端校验 `B_UserControl.ApplyTotalControl`：`cardAction==20` 合法，`cardValue` 允许 0-12、13-26（X1~X14）或 99；单控 `ChgUserRatePAIJI` 按原口径透传。
