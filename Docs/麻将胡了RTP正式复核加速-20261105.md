## 原因与改法

原流程逐个模拟完整付费回合及其全部免费再触发链。免费大奖方差大，为达到 ±1 个百分点通常需要大量完整回合；仅提前显示 2000 回合预览不能缩短正式复核。单纯把完整模拟换为原生计算仍不足以稳定达到本机默认配置的验收条件，因此同时改进计算核心和统计方式。

1. 将相同抽牌、补牌、金牌转百搭、连消、封顶和随机数规则实现为无外部导入的 WebAssembly 核心。固定数组减少分配和垃圾回收；每 50000 样本让出事件循环。保留 JavaScript 完整回合算法供兼容回退和对拍。
2. 独立估计普通旋转与免费旋转，用免费再触发的期望关系计算整条免费链，不截取前几次免费。
3. 对免费旋转采用重要性抽样，让罕见的起始中奖盘面更常进入样本，再按准确的抽样概率比还原贡献。保留没有起始中奖路径、但补牌后产生中奖的剩余贡献，不能忽略这部分。
4. 最多使用 8 个 Worker，固定分片和合并顺序，保留独立复核、取消、目标偏差、重算预算与保存门槛。

## 统计定义与审核要点

记普通完整旋转（含其全部连消）的返奖为 A、授予免费次数为 G，免费完整旋转返奖为 F、再授予免费次数为 H。各次免费旋转独立，H 的期望小于 1 时，整条免费链期望为 `E[F] / (1-E[H])`，每个付费回合自然 RTP 为：

`R = E[A] + E[G] * E[F] / (1-E[H])`。

A、F 均按固定 4000 原始押分归一化；默认权重与任意合法权重使用相同表达式。不包含人工赠送或吃分控制。

三组独立随机流分别估计：

- 原分布普通旋转的 `(A,G)`，包括二者协方差。
- 原分布免费旋转的 `(B,H)`。B 仅保留原始盘面不在重要性提议支持集中的返奖，包括补牌带来的中奖；保留 B、H 协方差。
- 重要性提议 Q 下的免费旋转，估计 `C = F / (Q/P)`。于是 `E[F] = E[B] + E_Q[C]`。

Q 是 9 种普通牌与前 3 轴各一个可见格组成的路径混合。概率比必须求和**所有能生成该盘面的路径**，不能只用本次抽中的路径。实际实现将路径和因式分解；审计用 240 张原始盘面、独立枚举 216000 条路径逐项对拍。抽牌、5 格位置及条件抽牌均按 32 位 RNG 的整数桶概率计算，不用理想化的连续均匀概率代替。

设 `d=1-H, u=(B+C)/d, v=G/d, w=G*(B+C)/d²`。最终估计量使用 delta method 的方差：

`Var(R) = Var(A+u*G)/n + Var(v*B+w*H)/f + v²*Var(C)/q`。

代码以 Welford M2 与协方差分子合并样本，再除以各组 `(count-1)*count`。这里是与原复核同类的统计近似区间，不是穷举精确解，也不承诺每次随机估计的真实误差必然在 1 个百分点内。非线性期望比使用一致的代入估计；没有用固定理论 RTP 冒充本次计算结果。

每组预先规定检查点 300 万、600 万、900 万、1200 万、预算末点，全部三组完成一个检查点才判断精度。最多五次查看使用原 `verificationZ(5)=2.57582930355`，允许一次校正时用十次查看的 Z 值，保留多次查看的 Bonferroni 修正。实际默认首个检查点为 **900 万个分组旋转观察值**，不是 900 万个完整付费回合。总预算不超过原 5000 万，余量不足一个分组时回退原验证器。

要求 H 的修正置信上界小于 1，统计量有限且方差为正；不可靠、生成超限或预算不足不会伪装成正式成功。精确零返奖仍只走原有可证明零返奖路径。单次旋转保留原连消生成上限；公式针对可终止的完整免费链，默认参数的全链生成上限也由完整回合对照验证。极端接近不终止的配置不纳入本次速度承诺。

## 页面和兼容性

- 正式 RTP 只在误差达标后允许保存；初始小样本估算不写入正式缓存或保存结果。
- 正式保存摘要保留方法标识、三个分组的统计量、总观察数和误差。仍兼容原完整回合的有效缓存及存储长度限制。
- “返奖分布”继续使用**独立 2000 个完整付费回合**，明确标注为独立估算，分母使用 `distributionCount`；不能用它反推正式 RTP，也不能用 900 万作分母。
- WebAssembly、子 Worker 或资源不可用时保留原完整回合计算回退，精度门槛不变，回退不承诺 3 秒。
- 配置切换、停止、重算、目标错过、一次校正、历史控制字段隔离与原流程兼容；所有脚本依赖带新的缓存版本。
