## 问题与影响面

- 基线：`Add-Phone-Support` 工作区；保留现有其他任务修改。本轮仅本地实现、构建和验证。
- F15/F16：AgencyInfo、AgencyRecord、UserRecord、GameRecord/TableRecords 直接访问时，`top` 是页面自己，缺少主框架的 `goldFormat`。将原函数及 `formatMoney` 原口径抽到 `Scripts/app/gold-format.js`，主框架与 `_ContentLayout` 同时加载，四页改为本页调用。框架仍暴露全局函数，其他既有 `top.goldFormat` 调用保持兼容。
- 配置：两个入口均从现有 `IsRMB`、`ExchangeRate` 注入；保留数字八位精度、兑换后两位小数及原字符串处理，不修改金额、鱼机下注缩放或输赢符号。
- F01/F11：GameRecordController 两个同名 POST Action 导致 MVC 在进入方法前抛 `AmbiguousMatchException`。保留无参实现（开放游戏、四类分组、显示名称、稳定排序及 children 契约），移除重复 FormCollection Action。现有唯一调用方 TableRecords 使用空 POST，不需要该参数版本。
- F03 仅回归：原 MemberAuthorize、AjaxOnly、HttpPost 保留。无新增权限、资金写入、管道或网络协议；客户端/APK、中心、子游戏、Robot 和 SQL 无需改动。
