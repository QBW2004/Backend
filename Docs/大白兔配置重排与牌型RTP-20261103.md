# 大白兔桌台配置与牌型 RTP

2026-11-04：本地实现与预览，未发布，未修改线上数据及 WebVer。最终要求为**每张桌台独立设置玩法规则**，页面隐藏留机模块；此前全桌共用与活动页编辑规则方案已撤回。本轮追加全部参数逐字段的页面提交、真实数据库回读和实际游戏服接收/结算检查。

## 界面与操作

桌台参数、牌型机会、玩法规则位于同一表单，仅在全部设置最底部保留“恢复默认”和“新建当前桌台/保存并热更新”。规则区标注“仅当前桌台”，正宗大四梅、五枚赠送、连庄、彩金各只有一份编辑表格，不展示原始 JSON。

正宗翻倍 X1～X14 可增删档位，支持相对权重或百分比输入。五枚中赠与落空各一行，修改一项百分比自动补足另一项至100%；概率最多六位小数，保存映射成现有整数权重及分子/分母，单纯切换模式保留原精确比例。

切换桌台分别保留各自的未保存草稿，包含尚未通过校验的输入和概率模式；迟到的载入或保存响应不会覆盖另一张桌。顶部刷新保留当前桌台选择并重新读取其规则，新建桌台使用独立默认规则。批量新建按当次表单参数各生成一份规则，创建后每桌仍可单独修改。

留机模块、导航与输入框不展示，原有 keepMax/keepMinHands 在载入、保存和恢复默认时保持原值；无服务端留机行为变更。全民赛跑的时段、名额和开关仍在活动配置统一管理。

## 按桌存储与保存

GetRabbitConfig(tableIndex) 与兼容 GetRabbitPayoutRules 均只读取本桌 cardgamecfg(GAME_ID=55,TableIndex)。已有独立行优先；旧桌缺行时只读沿用此前 rabbit_rules 的旧值，保存后成为独立行；新桌直接使用默认规则。读取不落库，也不影响其他桌。

统一 SaveTableConfig 请求携带 RabbitConfigJson，与本桌基础参数、牌型/鬼牌权重在同一事务保存。RabbitConfig.SaveTable 只校验本桌的最高押分及规则，只 upsert 本桌 cardgamecfg；不写 activityconfig.rabbit_rules，不遍历或校验其他桌台。任何校验或写库失败整笔回滚，提交后再发 RP/TC/PA/PC55 及机器人重载。

旧页面未携带 RabbitConfigJson 时，已有桌台保留并重新校验自己的规则；新建桌台写入独立默认规则。空 JSON 或向其他游戏携带 RabbitConfigJson 一律拒绝。旧活动页 Get/SaveRabbitConfig 接口停止全桌操作，旧规则专用 SaveRabbitConfig 入口要求使用桌台底部按钮，避免缓存页面覆盖各桌配置。

规则仍使用 schemaVersion=3，保留未知键并关闭已由全民赛跑替代的旧按桌 race.enabled。无需新增 SQL、游戏服、中心服或 APK。中心服现有 GetCardGameCfgs 已按 TableIndex 读取并下发各桌配置。

## RTP 口径

- 小四梅采用本桌 smallFourMultiplier。
- 正宗大四梅＝基础倍率×Σ(翻倍档位×权重)÷权重合计；关闭翻倍后只按基础倍率。
- 五枚赠送＝基础倍率×(自然中赠概率×中赠倍数＋落空概率×落空倍数)；关闭赠送后按基础倍率。
- 按本桌启用牌型的出现机会/10000加权。强出中赠概率用于指定送牌，不计入普通模型。
- 连庄受烧火窗口、奖池和屏蔽高奖影响，赛跑受活动时段及名额影响，两者需完整实测，不直接相加到此 RTP；人工控牌、比倍也不计入。

顶部仅保留一组牌型理论 RTP、基础牌型 RTP、正宗增量、五枚增量。数学模型直接使用同一份本桌编辑数据；无效或未载入规则时清空 RTP，避免显示其他桌的过期值。默认示例为81.30%基础＋2.00个百分点正宗＋约0.83个百分点五枚＝84.13%，不代表线上实测。
