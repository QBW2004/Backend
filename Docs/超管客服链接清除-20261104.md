# 超管客服链接（www.baidu.com）线上清除（2026-11-04）

**已上线执行，仅一行 UPDATE，无代码/版本改动。**

## 背景

超管名下玩家点客户端「客服」会打开 `www.baidu.com`。原因：`admin` 表 `atmadmin`（PRIV=0）行的
`CustomerServiceUrl` 字段存着历史占位值 `www.baidu.com`（2026-04-15 建号种子数据，历次导库沿用）。
玩家点客服 → `POST /api/CustomerServiceUrl` → `ResolveCustomerServiceUrl(users.AGENCY)` 只读直属代理
该字段原样返回（无回退，未配置返回空串）。

## 执行

1. 改前核查：`admin` 表唯一非空行即 `atmadmin='www.baidu.com'`；`users.AGENCY='atmadmin'` 的玩家
   （test01/test02/tt1/tt2/15002 等）受影响。
2. 改前 API 实测：`{"playerId":"test02"}` → `CustomerServiceUrl="www.baidu.com"`（复现）。
3. 备份：`mysqldump mth admin` → 服务器 `C:\MTH-Deploy\kefu-url-clear-20261104\admin_before_20261104.sql`。
4. `UPDATE admin SET CustomerServiceUrl=NULL WHERE ID='atmadmin' AND CustomerServiceUrl='www.baidu.com';`
5. 复核：`atmadmin.CustomerServiceUrl=NULL`，全表 `agents_with_kefu_url=0`；
   API 实测 test02/15002 均返回 `CustomerServiceUrl=""`。

## 客户端行为

接口仍 `code=10000` 成功、`CustomerServiceUrl=""`——按《客户端-客服链接空值处理-对接说明》
客户端应弹「当前代理未配置客服链接」，不再打开 baidu.com；未按对接改的客户端则 `OpenURL("")`
无反应（等同不跳转）。如需恢复，后台代理管理→行内「客服」改回即可。
