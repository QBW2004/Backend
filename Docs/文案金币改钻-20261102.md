# 后台文案「金币/币」统一为「钻」（2026-11-02，已实现未发布）

## 背景与范围

运营要求后台所有「金币」描述改成「钻」，并确认单独的「币」系文案一并统一（扣币/退币/购币/剩余币/游戏币/表头「币」等全部 → 钻）。此前手机端统计卡（送奖管理）已先行用过「（钻）」标注，本次把全端口径补齐。

## 改动方式

一次性脚本 `Tools/one-off/_rename_coin_to_diamond.py`（沿用上次 `钻→金币` 的 `_rename_diamond.py` 同目录惯例），在仓库根运行：

- 目标：`TTY.Web`、`YYT.BLL`、`YYT.Entity`、`YYT.Remote`、`UnitTestProj` 源码（.cshtml/.cs/.js/.config，跳过 bin/obj），共改 73 文件。
- 规则顺序：`金币`→`钻` → `游戏币`→`钻` → 保护哨兵 → `币`→`钻` → 还原哨兵。
- 保护词：`货币`（`游戏货币` API 参数、`加密货币` USDT 链接，非本货币）、`造币`（批量赋值造币注释），全库仅此 6 处保留「币」字。
- 逐文件保留 UTF-8 BOM 有无与 CRLF 换行；非 UTF-8 的 `jquery.fancybox.js`（第三方插件，无中文货币文案）自动跳过。

典型结果：`金币上限`→`钻上限`、`当前剩余金币：`→`当前剩余钻：`、`扣币`→`扣钻`、`退币`→`退钻`、`购币`→`购钻`、`剩余币`→`剩余钻`、`兑换金币数`→`兑换钻数`、`切换金币模式`→`切换钻模式`、MsgDefine `LKOK` 提示→`玩家钻充值、兑换操作成功。`、BLL 充退类型名 `case 23: return "扣钻"`、C#/JS/Razor 注释同步。
