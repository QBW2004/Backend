# 全民赛跑活动（后台活动配置 + 大白兔三端）

2026-11-03，本地实现并编译/单测通过；**未部署、未执行线上 SQL、未出 APK**。

## 需求口径

后台「系统设置 → 活动配置」新增「全民赛跑（大白兔）」：

| 配置 | 说明 |
|---|---|
| 开启/关闭 | 关闭后游戏服停发、客户端大厅不显示活动图标 |
| 每日开始/结束时间 | 北京时间 HH:mm；结束早于开始表示跨零点（如 22:00～02:00），凌晨段算前一天的名额 |
| 每日奖励总名额 | 全服所有大白兔机台共用；触发 1 次扣 1 个，用完当天停止派送，次日恢复 |
| 押分倍数 | 活动奖金 = 押分 × 倍数 |
| 触发牌型 | 可勾选四梅及以上：小四梅(7)、大四梅(8)、同花顺(9)、五梅(10)、同花大顺(11)、五兔王(12) |

例：倍数 10、押注 500、开出小四梅 50 倍 → 活动奖金 500×10=5000，牌型得分 500×50=25000，本局合计 30000。
游戏内先自动滚入活动奖金 5000，再播牌型中奖动画，动画结束后玩家点「得分」收 25000。

客户端大厅活动图标只在 **活动开启 + 大白兔(55)已启用 + 玩家所在代理线开放了大白兔** 时显示。

## 实现

**后台（MHT-Backend）**
- 表 `activityconfig`（`Docs/sql/全民赛跑活动配置-20261103.sql`，幂等，只建表不插行，未保存前活动为关闭）。
- `YYT.BLL/EF/RabbitRaceActivity.cs`：校验、JSON（与游戏服同名字段 `schemaVersion/enabled/startMinute/endMinute/dailyQuota/multiplier/types`）、北京时间窗口与活动日、按 `gameprizerecord` 中「全民赛跑」记录统计当日已派次数。
- `Areas/Game/Controllers/ActivityConfigController.cs` + `Views/ActivityConfig/Index.cshtml`（仅超管），菜单在「系统设置」下「客户端包管理」之后。保存后发 `PC(55)` 让中心服重推，下一手生效。
- 客户端接口 `GET /api/RabbitRaceActivity?account=玩家账号` → `{code:10000, datas:{show, open, startTime, endTime, multiplier, dailyQuota, remaining, typeText, types}}`；不带账号、活动关闭、55 未启用、代理线未开放 55、查询异常一律 `show=false`。
- 单测 `UnitTestProj/RabbitRaceActivityTest.cs` 5 项。

**中心服（MTH-Server/ServerCenterNew）**
- `Database::GetActivityConfig` 读 `activityconfig`（缺表/缺行返回 false）。
- `SendExtendedPara(55)` 在逐桌规则 0x5620 之后发 **0x5621**：`U16 jsonLen + CfgJson`；读不到时下发 `{"schemaVersion":1,"enabled":false}`。
- `UpdateGameConfig`（后台 PC 指令）对 55 也走 `SendExtendedPara`。此前大白兔逐桌规则保存后的 PC 热更并未重推 0x5620，这次一并补上。

**大白兔游戏服（ServerCardPhenix 源，MTH_DABAITU 编译）**
- `RabbitActivity.h`：配置解析、北京时间窗口、活动日、全服名额台账（纯逻辑，`tests/rabbit_activity_test.cpp` 29 项）。
- `ServerRun`：0x5621 接收；全服一份配置与台账（互斥锁），台账落盘 `log/DaBaiTu/RabbitActivity.dat`，重启后同一活动日不重复派发。
- `ServerHandler::SettleRabbitActivity`：换牌结算（`draw`，以及断线收尾代为换牌）后立即判定，命中即扣名额，并把奖金**直接加进玩家分数**，同时上报中奖记录「全民赛跑」（播报）、写余额。机器人不参与。同一手若按桌「全兔赛跑」也中，退回其预留额度，只发本活动。
- 活动命中的这手禁止比倍（与原全兔赛跑一致），快照新增 `activityAward` 与 `activity` 公示块。

**客户端（MTH-git）**
- 大厅 `LobbyRaceAnnouncement`：启动先隐藏入口（关图形与碰撞体，不停用节点）。登录后查询接口，此后每 60 秒刷新一次，换账号时立即重查。`show=true` 才显示入口，并把第一条公示填为：押分×倍数 / 开始 / 结束 / 牌型 / 总数 / 剩余，其余模板行隐藏。查询失败时保留上次结果。
- `RabbitGame`：换牌回包含 `activityAward` 时，翻完牌先显示「全民赛跑 +X」并只滚总分（WIN 框仍是待收牌型分），再播牌型中奖动画，最后才开放得分。比倍入口在活动手隐藏。
- `RabbitProtocol`：`RabbitState.activityAward/activity`，旧服务端缺省为 0/null。

## 上线顺序

1. 线上库执行 `Docs/sql/全民赛跑活动配置-20261103.sql`（先备份）。
2. 发布后台（含新 dll、`ActivityConfig/Index.cshtml`）。
3. 换 `ServerCenterNew.exe` 与 `ServerCardDaBaiTu.exe`（重启中心服会踢全部在线，按惯例择时）。旧游戏服收到 0x5621 按未知帧跳过。
4. 后台配置并开启活动。
5. 客户端大厅图标和游戏内滚分随下次 APK 生效。旧 APK 照常结算：活动奖金直接到账，但不单独滚分，大厅图标仍显示占位公示。

## 注意

- 名额以游戏服台账为准。后台「今日已派/剩余」和客户端「剩余」按中奖记录统计，属于公示口径；记录上报失败时可能比实际略多。
- 中奖记录 `RecTime` 按服务器本地时间写入，统计时按 UTC+8 换算。若服务器时区不是北京时间也能正确换算。
- 与按桌「全兔赛跑」（机台规则里的 race 段）相互独立。建议启用全民赛跑后关闭按桌赛跑，以免运营口径混淆。
