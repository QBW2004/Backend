# 玩家中奖历史共用大奖规则（后台 1.0.80）

2026-10-31 21:42 上线。

后台玩家「中奖历史」此前对牌机使用例外条件：只要属于牌机就展示，不要求满足大奖/播报资格，导致普通小奖混入。现在统一读取服务端结算时落库的 `IsBroadcast=1`，并要求 `Score>=0`，与大奖榜和播报使用同一次判定结果；后台不复制赔率阈值、不按金额另算大奖。

- 牌机普通小奖不再展示；手动送奖也必须满足相同大奖条件。
- 水果机额外玩法触发且赢分为 0 时，保留其合法大奖记录。
- 筛选发生在 `Count` 和分页之前，页面总数与每个游戏卡片的条数来自相同结果。
- 玩家列表与玩家详情的中奖历史入口共用 `GetPrizeHistory`。桌面端普通「游戏记录」用于流水审计，本次未改成大奖记录。
- 原有代理权限、玩家范围、游戏开关/八爪鱼排除、最近 7 天范围、机台名称和鱼机分数精度保留。
- 历史普通奖仍保留在明细表，只是本页面不再展示；不删除数据，不追溯重算过去的开奖。

手机页面提示改为「共 N 条大奖记录（与中奖播报使用同一规则）」。排行榜刷新频率和客户端播报逻辑不变。
