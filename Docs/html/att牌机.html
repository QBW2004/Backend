ATT3奖池完整规则： 1、鬼牌机制：1/2/3鬼牌仅作为手牌百搭凑牌型，无奖池加分、无领奖门槛限制，任意鬼牌数量开出大牌均可领取彩池；1/2/3鬼牌概率可独立自定义。 2、奖池加分机制：两项参数全部自定义，不写死；①奖池加分最低押分门槛：本局押分≥该分值才会加分；②达标后每局统一加分值：满足门槛时4个独立大奖池同步增加该分数；押分不足门槛无任何加分。 3、大牌领奖分层规则（比例/定额全部后台可自定义调整）： ①五条5.K：按配置比例领取超额全部浮动分，原厂推荐100%；领奖后五条奖池重置保底分； ②皇家同花顺R.S：按配置比例领取超额浮动分，原厂推荐区间70%~80%；领奖后RS奖池重置保底； ③同花顺S.F：按配置比例领取超额浮动分，原厂推荐区间20%~30%；领奖后SF奖池重置保底； ④四条4.K：不按浮动增量比例结算，领取固定小额定额彩金，超额奖池分数保留不扣除，领奖后四条奖池不回落保底；定额数值下方可自定义； 4、小牌权限：葫芦、同花、顺子、三条、两对、一对、杂牌无任何彩池领取资格； 5、关闭规则：对应鬼牌概率填0则对局不会生成该数量鬼牌；领奖比例填0则对应大牌无法支取彩池。

【动态RTP功能说明】 1、本表单位：万分比，杂牌出现率支持自定义手动输入，不自动覆盖；所有中奖牌型（一对～五条）数值自动求和； 2、实时动态计算：修改任意一行「出现率」或「普通档位倍数」，失去输入框焦点后，下方文字立刻重新计算并刷新RTP数值，非静态固定文字； 3、计算公式：RTP = Σ(该行出现率 ÷ 10000 × 普通档位基础倍数) × 100%； 4、数据边界：杂牌倍数固定0，不参与RTP计算；ATT3奖池额外浮动彩金/四条定额彩金不计入本表基础RTP； 动态展示：中奖牌型出现率合计：{sumRate} / 10000，实时理论返奖率 RTP = {rtpPercent}%
