## 规则 JSON

```json
{"schemaVersion":1,"specialRules":{"authentic":{"enabled":true,"multipliers":{"values":[1,2,3],"weights":[60,30,10]}}}}
```

- `enabled`：正宗大四梅总开关。关闭后自然/强出都不再翻倍，大四梅按普通牌型结算；**控牌指定倍数不受影响**。
- `multipliers`：X1~X14 倍数档 + 相对权重（0 不抽）。自然开出与难度强出统一按此抽取；触发排期（e_dif 难度、分池可负担）不变。

## 链路

保存 → `cardgamecfg` upsert（事务）→ PC 热更 → 中心服 `SendExtendedPara(5)` → 逐桌 `0x5620` 帧（TableIndex + JSON）→ phenix 服 `ReceiveRabbitRules` 校验入库 → 下一局 `MessageOnceCard` 应用。无配置行时 `phenixRules.configured=false`，算法完全走旧 `{6,3,1}` 逻辑。

兼容：旧版 phenix 服收到 0x5620 按"未实现命令"跳过载荷不断链；新 phenix 服配旧中心服收不到配置走默认档——两端可任意顺序发布，但**后台必须先于或同步于中心服换版**（否则保存后中心服不回推 phenix 规则）。
