# 牌机机器人数量框禁用修复（2026-10-30）

状态：2026-10-30 23:07随后台1.0.74上线，与麻将修正合并隔离发布。详见 [麻将胡了修正发布-20261030.md](麻将胡了修正发布-20261030.md)。

## 原因与修复

线上 1.0.73 的牌机机器人弹窗可以读取本线机台容量和已设人数，但机器人数输入框仍被禁用。例如火凤凰 / sucai 显示 24 台、当前 10 人，数量在允许范围内，仍无法编辑。

`resetCardCapacity()` 在读取容量前执行 numberbox 的 clear / disable。EasyUI 1.6.6 的 numberbox 与底层 textbox 分别缓存 disabled；clear 会同步底层状态。原回调先调用 enable（只改 textbox），随后重新初始化 min / max，又把 numberbox 缓存的 disabled=true 应用回 textbox。

`Areas/Game/Views/Robot/Index.cshtml` 在配置 min / max 时显式传入 `disabled:false`，同时恢复两层状态。仍保留无可用机台时的禁用、容量校验及异步响应版本检查。保存按钮原本可以点击；修复后可正常输入人数并提交。
