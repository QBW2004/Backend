# 麻将胡了 RTP 三秒估算

状态：2026-11-04 已本地实现并验证，未发布。

## 用户确认的验收口径

“3秒内出估算，精确复核继续”。不要求三秒内完成 ±1 个百分点的最终复核，也不降低最终保存门槛。

## 实现

- 当前权重复核和自动调权重启动后，先以独立随机流计算固定 2000 个完整付费回合，包含其全部连消和免费链。页面立即显示样本估算、样本数及“待精确复核”。这批样本仅用于显示，不进入正式搜索或独立复核。
- 自动调权重首先明确显示“调整前权重估算”，随后按搜索结果显示“候选权重估算”。通过正式复核之前，不修改页面权重。
- 进度独立显示，不再覆盖估算数字；精确复核继续使用原 5000 万局上限、检查点和 ±1 个百分点标准。正常中奖引擎、赔率、线上配置、服务端算法不变。
- 估算不写入可保存结果或缓存。取消、编辑、切换代理后，迟到消息失效；最终合格结果替换估算，保存仍需原精度校验。
- 固定无奖的精确 0% 走原证明路径，无须先估算。预览遇到长链超限时不显示部分样本，并继续原计算流程，避免阻止原本可成功的调权重。
- 修改两个产品文件：`TTY.Web/Areas/Game/Views/GameConfig/ConfigEditor.cshtml` 和 `TTY.Web/Scripts/app/mjhl.agent.rtp.worker.js`。Worker 入口缓存标记改为 `mjhl-agent-20261104-preview1`；数学规则及历史结果指纹未变化。

## 性能与验证

改前基准：本机单线程执行 10 万完整回合约 1.016 秒、50 万约 5.014 秒。该基准只是吞吐量测试，不能等同于达到 RTP 精度。

本机真实 Chromium、实际页面 DOM/函数及真实 Worker，最后一轮结果：

| 场景 | 首次估算耗时 |
| --- | ---: |
| 默认权重复核 | 0.168 秒 |
| 自动调权重的调整前估算 | 0.101 秒 |
| 关闭至尊 | 0.078 秒 |
| 关闭免费再触发 | 0.088 秒 |
| 金牌概率 100% | 0.117 秒 |
| Chrome 设置 CPU 降速 4 倍 | 0.247 秒 |
| 修改权重，包括原有 600 毫秒防抖 | 0.704 秒 |
| 精确 0% 最终结果 | 0.046 秒 |

以上是本机受控样本的页面显示时间，不是所有设备、网络和任意极端长链权重的硬实时保证。小样本波动较大，只作估算；正式复核的总时长未缩短，仍需要持续打开页面。
