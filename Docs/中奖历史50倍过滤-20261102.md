# 中奖历史只保留 50 倍及以上记录

2026-11-02 实现，未发布。

> 2026-11-02 后续配套（服务端仓库，未发布）：水果机播报/入榜门槛已提到 ≥50 倍（30/40 倍面板不再产生播报记录）；水浒传落库 `Multiplier` 改为实际奖项倍率（连线取最高中奖线倍率，不再被九线总注稀释），已播报的 50 倍连线大奖因此能正常进入本页。水果额外玩法仍入榜播报，不足 50 倍时按本页口径不展示。详见 `../../MTH-Server/docs/拉霸50倍播报入榜口径-20261102.md`。

运营要求：后台「中奖历史」只记录 50 倍以上的中奖，低于 50 倍的不再出现在中奖历史记录中。

## 口径

- `GetPrizeHistory` 在原有 `IsBroadcast=1 && Score>=0` 大奖播报规则之上，追加 `Multiplier >= 50`（`PrizeHistoryMinMultiplier = 50m`），过滤发生在 `Count` 与分页之前，页头中奖总数与每个游戏卡片的条数来自同一结果。
- 倍率直接取结算时中心服落库的 `gameprizerecord.Multiplier`，后台不另算倍率。
- 50 倍按「低于 50 倍不记录」理解为 `>= 50`（含 50 倍本身）。
- 鱼机 40~49 倍击杀、水果普通面板 30 倍奖等触发播报但不足 50 倍的记录，不再出现在中奖历史；播报与排行榜规则不变。
- 低于 50 倍的明细仍保留在 `gameprizerecord` 表（不删数据、不追溯重算），只是本页不再展示；`IsBroadcast` 语义不变，未触发播报的记录仍不展示。
- 玩家列表与玩家详情的中奖历史入口共用 `GetPrizeHistory`，一处改动两端生效；桌面端普通「游戏记录」（流水审计）不受影响。
- 原有代理权限、玩家范围、游戏开关/八爪鱼排除、最近 7 天范围、机台名称和鱼机分数精度保留。
- 手机页汇总提示改为「共 N 条大奖记录（仅统计50倍及以上中奖）」。
