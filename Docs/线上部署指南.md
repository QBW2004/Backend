## 📋 部署步骤

### 方案A：直接文件替换（推荐 - 快速部署）

#### 步骤1：备份现有文件
```bash

cd /path/to/website/TTY.Web/Scripts/app/phone/
cp phone.players.js phone.players.js.backup_20260906
```

#### 步骤2：上传新文件
将优化后的 `phone.players.js` 上传到服务器：
```

服务器路径：/path/to/website/TTY.Web/Scripts/app/phone/phone.players.js
```

#### 步骤3：清除浏览器缓存
由于是静态JavaScript文件，建议添加版本号参数：
```html

```

或者：
- 让用户强制刷新（Ctrl+F5）
- 等待浏览器缓存自然过期

#### 步骤4：验证部署
```bash

ls -lh phone.players.js
# 查看文件修改时间和大小
```

## 🔧 常见问题处理

### 问题1：用户反馈看不到控制状态
**原因**：缓存未更新  
**解决**：
```
1. 引导用户强制刷新（Ctrl+F5）
2. 或等待浏览器缓存过期
3. 或在服务器端修改JS文件URL添加版本号
```

### 问题2：刷新按钮没有防抖效果
**原因**：文件未成功更新  
**解决**：
```
1. 检查服务器上的文件是否是最新版本
2. 清除CDN缓存（如果使用CDN）
3. 检查浏览器控制台是否有JS错误
```

### 问题3：离线玩家加载仍然很慢
**原因**：后端数据库或网络问题  
**解决**：
```
1. 检查数据库索引是否正常
2. 检查网络延迟
3. 查看服务器资源使用情况
4. 查看数据库慢查询日志
```
