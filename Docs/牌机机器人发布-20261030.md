# 牌机机器人与登录原因码发布（2026-10-30，WebVer 1.0.72）

按用户“再部署一版”指令，20:37 完成后台 1.0.72、ServerRobot 与 12 款子游戏的隔离发布。中心服、麻将服和 Daemon 的文件/PID 保留。未发布客户端，未执行数据库迁移或修改机器人配置。

## 发布行为

- 五款牌机（火凤凰5、大字板15、ATT满花版25、点石成金37、NBA44）添加机器人改为选择代理线并输入增加人数，数量不能超过本线启用机台数；Robot 在本线随机遍历空机台、占用后换台、满台等待，机器人不能互顶，真人仍可顶替机器人。麻将胡了不接入机器人。
- 机器人列表及添加按代理线过滤；收回专属桌台时清理该批桌上的机器人配置并热更。
- 子游戏转发代理线登录拒绝原因：-6 对应 0x09（本线不可玩）、-5 对应 0x0A（客户端需升级）；冻结继续用原原因码。客户端显示专用文字仍需带相应客户端修改。
- 拉霸权重面板遇到无效/过期存量 profile 时显示默认试算与提示，未自动覆盖数据库配置。

基线为上次实际发布的 1.0.71：1548 个后台文件与发布前线上全量 SHA256 一致。后台最终仅 14 文件变化；更换 13 套 exe/PDB（Robot、2鱼机、2押注、5牌机、3拉霸），共26个文件。保持线上拉霸目录、数学模型、玩法及权重，未发布工作区既有拉霸全盘奖/附加玩法与目录更改；点石成金仍使用 ServerCardAtt3 和原奖池/状态路径。

Robot 沿用先前隔离源码的基础，只合入本轮数量规划、随机入座及重试修改；未引入工作区另外的 RobotBigWinLoop 定时虚拟中奖模块。旧 PDB 无源码校验和，保留原 PDB、本次隔离源与合并记录供核查。
