# 送奖记录行内移除（2026-11-03，已实现、未发布）

按运营最新要求，手机送奖明细中原显示“未开”的状态改为参考后台同款红色“移除”按钮。判断条件仍为执行中（Status=0）且尚无开奖时间。已开奖、已结束的记录保持原状态展示。

点击后显示带玩家账号的确认框；取消不提交。确认后按该行的记录ID、玩家账号和控制模式移除，不依赖当前查询账号或上方控制类型。提交期间禁用行内按钮，完成后刷新明细、余额及对应玩家当前控制。

新增带登录鉴权、POST和防伪令牌校验的 `/Game/PrizePool/RemoveRecord`，复用既有总控移除流程。保留原四参数 `CloseTotalControl` 方法及行为，新增带原记录ID的重载：在锁定玩家的事务中验证唯一执行中记录、原记录编号、操作人和未开奖条件。旧列表记录已被替换、已开奖、已结束或属于其他操作人时拒绝，不关闭后来新设的控制。

移除沿用原解除指令和发件箱重试，不删除历史、奖池关联或资金流水，不回退已结算资金；不改变送奖报价和计费规则。

产品改动：

- `Control.cshtml`：红色行内按钮样式。
- `phone.control.js`：按钮渲染、按行确认与提交、提交防重和刷新。
- `PrizePoolController.cs`：专用移除入口及参数、防伪校验。
- `B_UserControl.cs`：原记录与操作人校验，保留原移除方法兼容。
