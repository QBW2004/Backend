# 手机端剩余分数尾分显示为 0（2026-11-06，未提交、未发布）

## 需求（运营 2026-11-06 截图确认，后续补充）

玩家**不在游戏里**时，“剩余分数”只是离场时不足兑换 1 钻、留在 `users.GAME_SCORE` 的尾分（例：a18005 显示 27 分），统一**显示 0**；**钻按数据库里的整数钻显示**，不把尾分折算进位（运营选“钻不变，只显示整数”）。“不在游戏里”包括离线玩家，也包括在线但停在大厅/房间、没坐到机台上的玩家。坐在机台上的在线玩家继续显示准确机台分。

为什么不按尾分四舍五入进位：尾分 = 机台分 % 每钻分数，而每钻分数随游戏/房间/桌台不同（1、100 或桌台配置）。`users` 表没有记录这笔尾分来自哪个兑换比，离场后 `CURRENT_GAME/ROOM/TABLE` 也会清空，后台无法可靠折算。如果以后要进位，需要中心服在离场时把兑换比一起存库。
