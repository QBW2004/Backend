# 游戏配置：新建桌台自动命名、保存时选张数、修复数量输入框（2026-11-05）

状态：已本地修改并验证，已提交 `1a2b53b`，2026-11-05 19:12 已上线（1.0.107）。只改游戏配置页 `ConfigEditor.cshtml`（前端），后台 DLL、服务端、SQL、APK 均无改动。

## 需求与实现

1. **新建桌台（公共/专属）**：点桌台列表上方「新建桌台」直接进入新建表单，套用最近一张桌的参数，**桌名自动按顺序编号**（沿用最近一张桌的命名方式，取同前缀/后缀的最大编号 +1，如 `3号机`→`4号机`、`火凤凰12`→`火凤凰13`；没有可识别编号时为“张数+1号机”），可直接修改。
2. **右下角按钮**：新建时统一显示「保存」。点「保存」并通过全部校验（含开奖权重/规则组件）后，才弹出“新建几张桌台”；确认后按当前页面参数一次建好所填张数，各桌参数相同，桌名从当前桌名起顺延（`4号机、5号机…`；当前桌名没有编号时第 2 张起追加序号）。弹窗支持回车确认，取消不保存。已分配专属桌后再建公共桌的提醒保留在选好张数之后。
3. **选中已有桌台修改参数保存**：直接保存这一张，**不弹张数**；每张桌的参数仍各自独立保存。
4. **修复弹窗无法输入张数**：数量输入框在页面加载时于隐藏弹窗内初始化，实际输入区只有约 8 像素宽，看不见也点不中；现每次打开按样式宽度（90px）重排并自动聚焦全选，读取时以输入框当前文字为准（未失焦也能读到）。
5. **麻将胡了**：没有桌台，页面不显示新建/保存桌台入口，未改动。

## 补充：没有专属桌台的线也可直接新建（2026-11-06，未提交/未部署）

需求：例如游戏类型「鱼机类型」→ 金蟾捕鱼 → 代理 `sjxhly（用公共桌台）`，桌台列表上方也要有「新建桌台」。

- 前端：选中某线时不论是否已有专属桌台都显示「新建桌台」（与「从公共桌台复制一套」并列）；该线没有专属桌台时，新建表单取**公共桌台最近一张**的参数作模板、桌名从 `1号机` 起，并重新显示被隐藏的参数区。保存→选张数后，若该线首次建专属桌台，再确认一次：“新建后该线玩家只会看到专属桌台、不再看到公共桌台；可点「收回专属桌台」恢复”。
- 后台：`LineTables.ReserveNewLineTable` 去掉“该线须已有专属桌台”的限制（仍校验直属代理、`#`/空、麻将胡了、按类型上限）。需要换 `YYT.BLL.dll`，不只是视图。
