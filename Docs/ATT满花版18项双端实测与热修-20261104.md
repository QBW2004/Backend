## 查出的3处问题及上线内容

1. **中心服当前总控入口仍拒绝ATT扩展控值。** 1.0.101放开了旧控牌路径，但实际页面走UC32总控，另一处校验遗漏13～30。首个控制ID57收到UCER，没有下注。只给此入口追加 `cType==8 && cValue>=13 && cValue<=30`；9994项实际C++校验检查通过，旧版18项全拒绝、新版全接受，其他游戏边界保留。
2. **已入座玩家丢失奖池控制编号。** 中心修复后控制ID58确实开出普通满花三条6倍，却未产生奖池扣款。ATT等待/排队分支已有编号，入座分支遗漏 `mPrizeControlId=prizeControlId`；补齐这一行。
3. **金拇指错误上报为非人工控制。** 该分支的派奖上报把人工标志写死false，改为与普通派奖相同的 `1==mManualCtrlHit`。实际生产接收方法和金拇指调用方共668项检查通过（约2.4秒），包括等待、排队、已入座及5档金拇指。

第58条修复前试开已经实发6钻、未扣奖池，作为失败证据保留，不纳入36项通过结果，没有补扣历史或伪造AwardTime。修复后第59条同牌型实发/实扣6钻通过，纳入本次36项，后续60～94完整补齐其余两端项。
