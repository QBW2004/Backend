# 大白兔小四梅 50 倍与控牌补连庄牌型

2026-11-03 实现并验证，未发布。

## 需求

1. 大白兔（cardAction=20 / GameId=55）小四梅固定赔率由 40 倍改为 **50 倍**。
2. 大白兔控牌下拉补上原火凤凰后台已有的 **小四梅连庄 X2～X10**，即连送 2～10 手小四梅，每手按小四梅 50 倍结算。

## 口径

### 小四梅 50 倍

- 大白兔规则字段 `smallFourMultiplier` 默认值 40→50：后台 `RabbitConfig.DefaultJson`、`_RabbitConfig.cshtml` 表单默认值、服务端 `Rabbit::Config` 默认值同步。
- 控牌牌型文案/报价：大白兔倍率表 `dabaitu` 第 7 项 = 50，控牌显示 `小四梅(50倍)`；火凤凰仍为 40，不受影响。
- 既有桌 `cardgamecfg` 里保存的还是 40，必须执行 `Docs/sql/大白兔小四梅50倍-20261103.sql`（只把仍为 40 的桌改成 50，运营自定义的其他值不动）。
- 客户端 `RabbitRules.Multipliers[7]` 与本地模拟器 `local-demo.json` 同步改 50；正式服赔率仍以服务端下发的 `smallFourMultiplier` 为准。

### 连庄控牌

| 控牌值 | 文案 | 总赔率 |
| --- | --- | --- |
| 27 | 小四梅连庄X2 | 100 倍 |
| 28 | 小四梅连庄X3 | 150 倍 |
| … | … | … |
| 35 | 小四梅连庄X10 | 500 倍 |

- 控牌值 27-35 仅对大白兔开放，避开已有的 0-12 基础牌型、13-26 正宗大四梅和 99 关闭。
- 服务端 `Rabbit::State::Force(count)` 记录待送手数；`AlgProb` 在 `forcedHand` 时强制 `e_4_OF_A_KIND_L`，连庄计划优先于同时存在的普通放水控牌（三条/对子/两对），不会被 `UserCtrl()` 默认放水覆盖。
- 每手都是独立的小四梅结算（押分 × 50），不是一次乘 N；第 N 手后强制连庄结束，烧火窗口按配置 `burnRounds` 展示。
- 手机端「1 次（5 把之内）」只约束命中窗口：5 把内命中后，连庄本身仍按 X2～X10 送满 N 手。
- 首手沿用大白兔连庄首手牌型（王 + 两张同点数），后续手按配置的双王/王在前概率；玩家全留或拆掉核心牌时本手可能不中，强制手数不会因失败而减少，下一手继续补。
- 连庄开关 `specialRules.streak.enabled` 关闭时，人工连庄控牌仍按上述口径强制生效（开关只控制自然随机连庄）。
- 代理送奖奖池：控牌值 27-35 的报价按 N×50 倍备足；服务端每手命中都以同一控制编号上报，奖池逐手扣减，总扣减与报价一致。连庄期间不再把 `UserCtrl()` 默认放水误记为控牌命中。
- 报价按送奖时的当前押注计算；玩家在连庄期间改加油会按新加油额逐手结算，运营需按实际押注留足奖池（奖池透支沿用既有欠额口径，不阻断已开始的连庄）。
- 强制连庄状态只在游戏进程内存中，不写入 `RabbitState-<桌号>.dat`；游戏服重启会中断剩余手数，不会出现重启后无控制编号却继续送奖的资金风险。玩家起立/离桌/超时踢起或换人坐下时也会清空，避免下一位玩家继承剩余手数。

- `Tools/RabbitSimulator/Config/local-demo.json`、`Docs/大白兔四项玩法可配置规则-20261101/规则与配置说明.txt`：本地演示默认 50。

## 发布

1. 先备份 `cardgamecfg`，执行 `Docs/sql/大白兔小四梅50倍-20261103.sql`。
2. 换 `ServerCardDaBaiTu.exe`/PDB（含 `ForcedAward` 与连庄控牌）；火凤凰 `ServerCardPhenix.exe` 同源码也需同批构建，避免后续单独换火凤凰时缺少共享符号。
3. 后台换 DLL 与 `phone.core.js`/两个用户管理视图/`Config/card-prize-quotes.json`，递增 `WebVer` 刷新手机脚本缓存。
4. 客户端静态倍率表只影响本地演示和首帧，正式赔率由服务端配置下发；如需本地演示 50，随下次 APK 生效。
5. 发布后抽查一张大白兔桌：`SELECT JSON_EXTRACT(CfgJson,'$.smallFourMultiplier') FROM cardgamecfg WHERE GAME_ID=55` 应为 50；控牌下拉可见 `小四梅(50倍)` 与 `小四梅连庄X2(100倍)`～`X10(500倍)`。
