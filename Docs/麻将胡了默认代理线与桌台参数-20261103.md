## 配置链路（本次核对结论）

- 实际押注/兑换/档位全部来自 `mjhl_agent_config`（代理线独立配置）：
  - 游戏服 `MjhlSession` 入座取 `GetAgentProfile` → `mBetLadder=chips`、`_oneCoinScore=scorePerCoin`，登录/加载回包下发 `bet_min/bet_max/bet_default/score_per_coin`。
  - 未配置时付费局回 `config_missing`，只有免费链可用。
- 房间级 `parabetroom`（经中心 `GetBetPara`）是登录房间参数来源：`COIN_SC` → 游戏服 `ServerRun::oneCoinScore`，影响登录回包 `score_per_coin` 与钱包推送兜底比率；旧值 100 会先按 1:100 显示再被代理配置纠正，本次改为 1。
- `roomtableconfig`（默认桌台）已含 BetMax=60/OneCoinScore=1/ExchangeRate=1:1，最小 0.4 由 `cardpayoutprofile` HandType=2200 哨兵（PayoutMultiplier=4、ProbabilityBasis=600、StockLimit=50）表达，整数列无法存 0.4，故 BetMin 保持 0。
- `roomtableconfig_bet` 的 54 行按拉霸设计保持全 0 + BetScores 空串（下发时由 parabetroom 补填）。
- `paralaba`/`gameconfiglaba` 已是 ×10 口径（BetMin=4/BetMax=600/CoinSc=1/ExCoin=1），无需改。
