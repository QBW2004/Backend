# 牌机送牌换牌命中与离场记账修复

状态：**本地修复、定向验证、七工程 Release x64 与隔离发布包完成，未发布、未操作线上资金或历史记录。** 基线为已上线的后台/服务端 1.0.104。

## 修复行为

1. 点石成金、大字板、NBA、火凤凰、大白兔及未开放的金皇冠：有送奖编号、剩余次数且本手命中概率门时，一手组成成立的指定牌面，二手保持该目标牌面；保留或更换任意组合不会把已消耗的送牌变成其他牌型或零奖。ATT 的已发布保证出牌逻辑保留。
2. `Common/CardGiftCards.h` 集中保存基础牌型构造，按游戏控制类型隔离；请求只作用于一手。没有送奖编号、未命中概率门、自然局、默认循环、点杀沿用原算法。对有编号的控制增加命中检查，避免原算法补对子时误消耗未选中的送牌。
3. 六款在服牌机及金皇冠统一使用 `ReportCardAward`：正常二手、进入比倍、主动收奖和离场自动收尾共用，每手由独立标记防重复。首手后直接离桌或断线，自动二手/收奖会补发真实开奖事件，不再只加玩家分数而漏掉送奖明细和奖池支出。
4. 火凤凰/大白兔五梅和正宗大四梅、大字板/金皇冠正宗大四梅，保留最终金额确定后上报；进入比倍前完成原牌型记账，后续比倍金额不重复计入该笔送奖。ATT 普通/正宗满花、方块彩金和金拇指仍按实际牌面、档位与奖金命名记账。
5. 大白兔连庄 X2～X10：整组保留原控制编号、逐手记奖池，最后一手才消耗该组次数并切回默认循环；后续连庄手不重新抽触发概率或重置手数。新控制编号会清除前一笔未完成的强制计划，防止串号。原有离座/重启不持久化强制剩余手数的规则保留。

本次未改变倍率、概率、桌台配置、奖池存储过程、后台页面或玩家协议；无 SQL、WebVer、APK 变更。代码修复不会自动补记 173/174 或退还既有错扣，历史更正仍须逐笔核实后另行执行。

## 获批上线后最短客户端验收

使用运营指定的测试账号和已批准预算，每款各测一笔低金额送奖：

1. 首手后任意改变留牌，再开二手，核对指定牌型、得分、送奖明细和唯一支出流水。
2. 再送一笔，首手后直接离桌或断网重连，核对自动到账与唯一送奖/奖池记录。
3. 已正常开奖后再离桌，旧送奖金额与牌型不再变化；继续普通局不再扣该笔奖池。
4. 大白兔 X2 两手逐笔记账、整组结束后无额外扣款；火凤凰/大白兔正宗与五梅，以及 ATT 金拇指各核对一次最终金额。
